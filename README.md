# Minecraft Modpack & Map Archive

## Repository Notice

This repository is a personal archive used to record **high-quality Minecraft modpacks and maps** that I am interested in or have previously played. It includes brief descriptions and my personal evaluations of these projects.

The files are stored here only to make access more convenient for users who may have difficulty downloading them from other platforms.

However:

- If you are able to do so, please download these projects from their **original release platforms** to support the creators.
- Do **not** use the resources in this repository for other purposes.
- **Redistribution of any content from this repository is strictly prohibited.**
- This is a **private repository**. Internal users are asked **not to share its contents externally**.

## Genre Notes

- **CTM (Complete the Monument):** Collect objective items to complete a monument while progressing through structured challenge areas.
- **Roguelike:** Run-based progression, upgrades, and repeated high-difficulty challenges.
- **Survival Overhaul:** Modpacks that significantly increase the realism and difficulty of Minecraft survival.
